Tajiri POS

Windows installer

Download the 103 MB installer for Windows 10 or 11 (64-bit). The download is checked and assembled on this device before saving.

Download the installer while online, then run it to install the desktop app. Local POS data can be used offline after setup; Supabase sign-in, cloud sync, staff account changes, and online payments require an internet connection. If the download is interrupted, reconnect and try again.
