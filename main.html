Download & install options
Download the Windows desktop app

Install on Windows with Microsoft Edge or Chrome using the install icon in the address bar, or use the browser menu and choose Install Tajiri POS. On a phone, use the browser menu (or Share menu on iPhone) and choose Add to Home Screen. Open the app once while online so its screens are saved for offline use. Signing in and cloud sync still require internet.
